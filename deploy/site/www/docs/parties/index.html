Créer et rejoindre une partie

Une personne héberge la partie sur son PC : c'est l'hôte. Les autres la rejoignent avec un lien d'invitation.

Avant de commencer

  • Chaque joueur a installé son jeu dans la Bibliothèque (voir Premiers pas).
  • Chaque joueur prépare son fichier d'options (YAML), au même format que pour Archipelago, souvent à partir du modèle fourni avec le monde du jeu. Le champ name donne le nom du joueur dans la partie (son « slot »).
  • Les joueurs envoient leur YAML à l'hôte.

Créer la partie (hôte)

  1. Dans la barre de gauche, ouvrez Parties › En cours, puis cliquez sur Créer depuis des YAML.
  2. Dans Joueurs, cliquez sur Ajouter des YAML… et choisissez un fichier par joueur.
  3. Apworlds : les mondes installés par la Bibliothèque sont repris tout seuls. N'en ajoutez d'autres que si vous leur faites confiance : un apworld est du code qui s'exécute sur votre PC.
  4. Dans Serveur, gardez le port 38281 sauf raison contraire. Le mot de passe de la salle est facultatif.
  5. Adresse publique : votre nom de domaine ou votre adresse IP publique. C'est elle qui sera écrite dans les invitations.
  6. Chiffrement : « Chiffré (wss) » demande un certificat et sa clé privée (fichiers PEM) pour votre nom de domaine. Sans certificat, choisissez « En clair (ws) » ; le mot de passe de la salle passe alors en clair sur le réseau.
  7. Choisissez un préréglage : Rapide, Standard ou Long.
  8. Facultatif : un webhook Discord, pour poster les grands moments de la partie dans votre salon.
  9. Cliquez sur Générer la partie.

La première fois, Raftup propose d'installer le générateur officiel d'Archipelago (environ 72 Mo). Il est téléchargé une seule fois, puis lancé dans un process séparé, en bac à sable sous Windows.

Une fois la partie générée, le serveur intégré la met en ligne. L'écran Partie en cours montre les joueurs, la progression, une durée estimée, le chat et le journal.

Vous avez déjà un fichier .archipelago généré ailleurs ? Utilisez Héberger un fichier .archipelago.

Inviter les joueurs

  • Copier le lien, sous un joueur, copie son lien personnel, avec son slot. C'est le plus simple : envoyez-le-lui par message.
  • Copier l'invitation, en haut de l'écran, copie un message pour tout le groupe : l'adresse, la liste des joueurs et un lien commun, sans slot.

Un lien ressemble à raftup://join?v=1&addr=…&slot=Bob&game=…. Le mot de passe de la salle n'est jamais mis dans un lien : donnez-le à part.

L'onglet Salon montre qui est prêt. Le test « prêt » passe par une vraie connexion au serveur : un joueur prêt pourra vraiment se connecter.

Joueurs hors de chez vous : votre box doit laisser passer le port choisi (TCP 38281 par défaut) vers votre PC. Cherchez « redirection de port » dans l'interface de votre box. Une adresse localhost ne marche que sur votre propre PC.

Rejoindre une partie (joueur)

  1. Cliquez sur le lien reçu : le launcher s'ouvre. Certaines applications, comme Discord, ne rendent pas ces liens cliquables : copiez alors le lien, ouvrez Parties › Invitations, collez-le puis cliquez sur Lire le lien.
  2. Vérifiez le serveur, le jeu et le slot, puis cliquez sur Continuer.
  3. La Bibliothèque s'ouvre avec l'adresse et le slot déjà remplis. Ajoutez le mot de passe de la salle s'il y en a un.
  4. Cliquez sur Lancer le jeu.

Selon le mod, Raftup transmet l'adresse au jeu tout seul, ou la copie dans le presse-papiers avec la marche à suivre. Pour Slime Rancher, la connexion se fait dans le jeu : menu Options, puis le menu de connexion du mod.

Pendant la partie

Le serveur de Raftup comprend les commandes habituelles, à taper dans le chat de votre client :

CommandeEffet
!hint <objet>demande où se trouve un objet (coûte des points d'indice)
!remaining, !missingce qu'il vous reste à trouver
!release, !collectenvoyer vos objets restants, ou récupérer les vôtres, après l'objectif
!away, !backsignaler une absence, puis votre retour
!summaryrésumé de ce qui s'est passé depuis votre dernière visite
!vote_release <joueur>voter pour libérer les objets d'un joueur qui abandonne

!help donne la liste complète.

Arrêter et reprendre

La partie est sauvegardée à chaque objet, dans un fichier .raftup à côté de la seed. Fermer le launcher arrête la partie proprement. Quand vous hébergez de nouveau la même seed, elle reprend là où elle en était, sans objet perdu ni en double.

RAFTUP

Launcher multiworld libre, compatible avec Archipelago. Projet indépendant : aucun jeu ni ROM fourni.

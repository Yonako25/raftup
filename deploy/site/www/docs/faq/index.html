Aide

Questions fréquentes

Les réponses courtes. Pour le pas-à-pas, voir les autres guides.

Raftup et Archipelago

Raftup remplace-t-il Archipelago ?

Non. Raftup est une implémentation alternative, compatible avec Archipelago : même protocole réseau, mêmes mods de jeux, mêmes fichiers d'options. Il utilise d'ailleurs le générateur officiel d'Archipelago, à une version épinglée.

Raftup est un projet indépendant, sans lien officiel avec l'équipe d'Archipelago.

Mon mod Archipelago marche-t-il avec un serveur Raftup ?

Oui, c'est la règle de base du projet : un mod existant se connecte au serveur de Raftup sans aucune modification. Le serveur est testé en comparant ses réponses à celles du serveur officiel.

Puis-je rejoindre une partie hébergée ailleurs ?

Oui. Dans la Bibliothèque, remplissez l'adresse, le slot et le mot de passe de la partie, puis lancez le jeu. Raftup installe le mod ; la partie, elle, peut tourner sur n'importe quel serveur compatible.

Quelle version d'Archipelago Raftup suit-il ?

Chaque version de Raftup épingle une version d'Archipelago. Elle est affichée en bas à gauche du launcher (par exemple « Compatible avec Archipelago 0.6.8 »).

Jeux et mods

Raftup fournit-il les jeux ou des ROM ?

Jamais. Raftup installe des mods sur votre propre copie du jeu, achetée de votre côté. Il ne distribue ni jeu, ni ROM, ni clé, ni asset.

Pourquoi si peu de jeux ?

Un jeu n'entre au catalogue qu'après une vraie partie, avec le mod de son auteur, à une version vérifiée. Le catalogue grandit petit à petit. Vous pouvez proposer un profil par pull request : voir la page des jeux.

Mon jeu n'est pas détecté.

Raftup cherche dans Steam et Epic. Pour une autre installation, utilisez Ajouter un dossier de jeu dans la Bibliothèque et choisissez le dossier qui contient l'exécutable du jeu.

Comment remettre mon jeu comme avant ?

Dans la Bibliothèque, choisissez le jeu puis Désinstaller le mod. Raftup retire ce qu'il a installé et les fichiers que le mod a créés.

Est-ce que je peux ajouter un apworld téléchargé ailleurs ?

Oui, dans « Créer une partie », section Apworlds. Attention : un apworld est du code Python qui s'exécute sur votre PC pendant la génération. N'ajoutez que ceux dont vous connaissez l'auteur.

Sécurité

Windows affiche un avertissement au lancement.

Windows SmartScreen se méfie des programmes récents et peu téléchargés. Vérifiez l'empreinte SHA-256 du fichier avec celle publiée dans la release, puis choisissez « Informations complémentaires » et « Exécuter quand même ».

Les mises à jour automatiques sont-elles sûres ?

Chaque version du launcher est signée par la mainteneuse du projet. Le launcher vérifie cette signature avant de remplacer son exécutable : une version modifiée en route est refusée.

Faut-il chiffrer ma partie ?

C'est conseillé dès que des joueurs viennent d'Internet : en clair (ws), le mot de passe de la salle et les messages passent lisibles sur le réseau. Le chiffrement (wss) demande un certificat pour votre nom de domaine.

Comptes et Rafthub

Un compte est-il obligatoire pour jouer ?

Non. On crée et on rejoint une partie sans compte. Le compte Rafthub sert aux amis et à la présence.

Quelle différence entre le Rafthub officiel et un Rafthub auto-hébergé ?

Le Rafthub officiel est le service du projet : rien à installer, le launcher s'y connecte par défaut, et il peut proposer la connexion avec Discord.

Un Rafthub auto-hébergé tourne chez vous, pour votre groupe : connexion par pseudo ou e-mail et mot de passe, sans Discord. Les comptes d'un hub ne sont pas ceux d'un autre. Voir Héberger son propre Rafthub.

Comment changer de hub ?

Ouvrez un lien raftup://hub/… donné par l'administrateur du hub, ou tapez son adresse en bas de l'écran « Amis ». Le bouton Par défaut revient au Rafthub officiel.

Puis-je changer de pseudo ou supprimer mon compte ?

Le pseudo se change dans l'écran « Amis », une fois par 24 heures. Rafthub permet aussi d'exporter ses données et de supprimer son compte avec tout ce qui s'y rattache.

Le projet

Raftup est-il gratuit ?

Oui, et son code est ouvert : MIT ou Apache-2.0 pour le launcher et le serveur, AGPL-3.0 pour Rafthub. Voir les mentions et licences.

Et sur macOS ou Linux ?

Le code compile et passe ses tests sur les trois systèmes, mais seul le launcher Windows est publié pour l'instant. Rafthub, lui, existe déjà pour Linux et Windows.

J'ai trouvé un bug.

Merci ! Ouvrez un ticket sur GitHub, avec la version du launcher et ce que vous faisiez.

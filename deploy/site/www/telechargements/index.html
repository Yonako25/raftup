Récupérer Raftup

Tous les fichiers sont publiés sur la page des releases GitHub du projet, avec leur empreinte SHA-256. Raftup est gratuit et son code est ouvert.

Pour jouer

Launcher Raftup pour Windows

Un seul fichier .exe, sans installation ni droits d'administrateur. Il se met ensuite à jour tout seul, avec des versions signées.

raftup-windows-x86_64.exe

Télécharger sur GitHub Premiers pas

Configuration

  • Windows 10 ou 11, 64 bits.
  • Une copie légale des jeux auxquels vous jouez (Steam, Epic…).
  • Une connexion Internet pour installer les mods et, la première fois, le générateur.

macOS et Linux : le code compile et passe ses tests sur les trois systèmes, mais seul le launcher Windows est publié pour l'instant.

Rafthub

Comptes et amis : deux versions

Rafthub est le service qui gère les comptes, les listes d'amis et la présence. Il n'est pas nécessaire pour jouer : une partie se crée et se rejoint sans compte. Il existe en deux versions, avec le même code.

Rien à installer

Rafthub officiel

Le service du projet Raftup, à l'adresse hub.raftup-games.com. Le launcher s'y connecte par défaut : il suffit de créer un compte dans l'écran « Amis ».

  • Connexion par pseudo ou e-mail, et mot de passe.
  • Connexion avec Discord, quand elle est activée.
  • Amis de toute la communauté Raftup.

Rafthub auto-hébergé

Votre propre Rafthub, sur votre serveur ou votre PC, pour une communauté privée. Base de données intégrée, assistant d'installation dans le navigateur, HTTPS intégré en option.

  • Connexion par pseudo ou e-mail, et mot de passe.
  • Pas de connexion Discord dans cette version.
  • Vous gérez les joueurs, les inscriptions et les invitations.

Vérifier un fichier

Chaque fichier a son empreinte à côté de lui (.sha256). Sous Windows, dans PowerShell :

Get-FileHash .\raftup-windows-x86_64.exe -Algorithm SHA256

Sous Linux :

sha256sum -c rafthub-linux-x86_64.tar.gz.sha256

Code source

Le code de Raftup est sur GitHub. Le launcher, le serveur de parties et les bibliothèques sont sous MIT ou Apache-2.0, au choix. Rafthub est sous AGPL-3.0 : ses archives contiennent la licence et le lien vers son code.

Catalogue

Jeux pris en charge

Chaque jeu du catalogue a un profil d'installation public, dans le dépôt de Raftup. Le profil dit quoi télécharger, où, à quelle version, et avec quelle empreinte. Le catalogue est embarqué dans le launcher.

SR

Slime Rancher

Disponible Windows Steam

Le premier Slime Rancher (pas le 2). Raftup détecte l'installation Steam, installe MelonLoader puis le mod Slimipelago, et ajoute le monde du jeu au générateur. Le mod se connecte au serveur de Raftup sans modification.

ComposantVersionAuteur
MelonLoader (chargeur de mods)0.7.3LavaGang · Apache-2.0
Slimipelago (mod du jeu)0.3.2.1SWCreeperKing
Monde Slime Rancher (apworld)0.3.2.1SWCreeperKing

Connexion : dans le jeu, menu Options, puis le menu de connexion du mod. Raftup copie l'adresse et le slot : il suffit de les coller.

Les fichiers sont téléchargés depuis les pages de leurs auteurs, sur votre PC. Raftup ne les redistribue pas.

D'autres jeux arrivent

D'autres jeux PC, sans ROM, sont en préparation. Un jeu n'entre au catalogue qu'après une vraie partie, avec le mod de son auteur, non modifié.

Les jeux de consoles Nintendo actuelles ne seront pas ajoutés.

Proposer un jeu

Les profils vivent dans le dossier profiles/ du dépôt, un fichier TOML par jeu. Une proposition passe par une pull request ; la CI vérifie le profil (empreintes, domaines autorisés, chemins).

Un mod sans licence n'est ajouté qu'avec l'accord écrit de son auteur.

Voir les profils sur GitHub

Les noms de jeux cités appartiennent à leurs éditeurs. Raftup n'est affilié à aucun d'eux et n'utilise aucun visuel officiel : les jaquettes du launcher sont de simples aplats de couleur.

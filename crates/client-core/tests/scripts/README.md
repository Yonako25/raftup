# Scripts de test manuels

- `faux_joueur.py` : faux joueur Slime Rancher (slot `Rancher1`) qui se connecte au serveur sur `ws://127.0.0.1:38281`, visite quatre lieux et écrit dans le chat. Il a servi à vérifier l'exemple `suivi` (jalon J0) contre le serveur officiel. À lancer avec le Python autonome de l'étape 0 (bibliothèque `websockets`).

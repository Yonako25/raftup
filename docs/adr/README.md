# Décisions d'architecture (ADR)

Une décision par fichier, numérotée : `0001-titre-court.md`.
On n'efface jamais un ADR : s'il est remplacé, on change son statut et on renvoie vers le nouveau.

## Modèle

```markdown
# 0001 — Titre

- Statut : proposé | accepté | remplacé par 000X
- Date : AAAA-MM-JJ

## Contexte
Le problème, et pourquoi il faut décider.

## Décision
Ce qu'on fait.

## Conséquences
Ce que ça implique, en bien et en moins bien.
```

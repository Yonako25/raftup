## Bloqués (aucun profil), avec la raison

| Jeu | Raison | Décision possible |
| --- | --- | --- |
| A Hat in Time | mod publié seulement sur le Steam Workshop ; branche bêta Steam `tcplink` ; passe par le client Python d'Archipelago | hors de portée du format |
| Bumper Stickers | le « jeu » est un programme gratuit fait pour Archipelago (pas un mod d'un jeu possédé), sans licence | accepter les jeux gratuits à télécharger (ADR) |
| Celeste 64 | le « mod » est le jeu complet (jeu gratuit de Maddy Makes Games, avec ses assets) | idem |
| Celeste (Open World) | le chargeur Everest s'installe en exécutant `MiniInstaller`, qui patche `Celeste.exe` | prérequis installé par le joueur (Olympus), ou ADR pour exécuter un installateur |
| ChecksFinder | jeu gratuit fait pour Archipelago (MIT), pas un mod | accepter les jeux gratuits à télécharger (ADR) |
| Civilization VI | mod dans `Documents\My Games\…` (hors du dossier du jeu), fichiers propres à chaque partie, client Python d'Archipelago obligatoire | hors de portée du format |

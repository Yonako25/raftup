# Brouillon : demande d'autorisation à l'auteur de Slimipelago

> À envoyer par l'utilisatrice elle-même (issue GitHub ou Discord). Rien n'a été envoyé.

Bonjour SWCreeperKing,

Je développe Raftup, un launcher de bureau compatible avec le protocole d'Archipelago.
Il aide les joueurs à installer les mods de jeu depuis un profil déclaratif.

Pour Slime Rancher, j'aimerais que Raftup installe Slimipelago (v0.3.2.1) chez le joueur.

- Raftup ne redistribue rien : il télécharge `Slimipelago.zip` et `slime_rancher.apworld` directement depuis vos releases GitHub.
- Il vérifie le sha256 avant d'extraire, puis copie les fichiers dans le dossier du jeu du joueur.
- Le crédit à votre nom est affiché dans le launcher, et le joueur peut tout désinstaller en un clic.

Le dépôt n'ayant pas de licence, j'ai besoin de votre accord écrit.
Seriez-vous d'accord ? Une courte réponse suffit ; je garderai le lien de votre message dans le profil (`permission_url`).
Vous pouvez aussi ajouter une licence à votre dépôt, ce qui règlerait la question pour tout le monde.

Merci pour votre travail sur le mod !
